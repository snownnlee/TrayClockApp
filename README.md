# TrayClockApp

一款 Windows 桌面悬浮时钟应用，常驻桌面（可隐藏），实时显示时间、网速、内存和电量信息，支持从系统托盘快速控制。

## 主要功能

- **悬浮显示**：时钟条固定在桌面顶部并置顶，不会遮挡操作，可随意拖动位置
- **信息丰富**：时间、实时网速、内存占用、电池电量一目了然
- **透明无边框**：默认半透明，不干扰桌面观感，透明度可自行调节
- **显示项可配置**：时间、网速、内存、电量可独立配置
- **配置自动保存**：位置、透明度、开关设置等自动保存

## 使用说明

- **拖动**：按住悬浮条左键拖动，可放到屏幕任意位置
- **右键菜单**：在悬浮条上点击右键，可打开功能菜单（显示/隐藏、置顶、透明度、组件开关、重启、退出等）
- **系统托盘**：任务栏右下角托盘图标提供同样的菜单入口

## 环境要求

- Windows 10 或 Windows 11

## 发布生成

双击运行根目录下的 `publish.bat`，即可将程序打包为单文件发布到 `publish/` 文件夹，方便拷贝到其他电脑使用（发布前需安装 .NET SDK 10）。
